import { Aside, Steps } from "@astrojs/starlight/components";

ショップが1件も登録されていない間は、どの画面を開いてもこのウィザードに案内されます(URLは`/setup`)。ログイン画面については[ログイン](/docs/user-guide/login/)を参照してください。通常モードで未ログインのままここに来た場合は、先にログイン画面と同じ内容が表示されます。

![未ログイン時のウィザード](/docs/screenshots/setup-not-logged-in.png)

<Aside type="tip">
	通常モードでは、まだ誰も登録されていない状態で最初にログインしたアカウントが自動的に管理者になります。2人目以降のメンバーを迎える場合は、先に[許可ユーザーとして登録](/docs/admin-guide/settings/#許可ユーザー)しておく必要があります。
</Aside>

<Steps>

1. **プラットフォームとショップ名を入力**

   ![ステップ1: ショップ作成](/docs/screenshots/setup-step1-shop.png)

2. **連携設定**(スキップ可能、あとから[ショップ設定](/docs/admin-guide/shops/)でも変更できます)

   デモモードでは「デモモードのため、BASEとの連携はできません」と表示され、連携操作自体ができません。通常モードでは実際に「連携する」ボタンからBASEの認可画面が開き、認証コードを貼り付けて連携します。どちらのモードでも、注文の管理画面URL・商品ページURL・商品編集ページURLのテンプレートはここで設定できます。

   ![ステップ2: 連携設定(デモモードの例)](/docs/screenshots/setup-step2-connect.png)

3. **デモ用のサンプルデータを投入するか選択**(デモモードのみ、通常モードではこのステップ自体が無い)

   チェックを入れたまま完了すると、部品・BOM・注文・発注が入った状態で始められます。プラットフォームに「手動管理(API連携なし)」を選んだ場合も、商品管理(手動)の商品・バリエーション込みのサンプルデータが入ります(内容の詳細は[デモモードとサンプルデータ](/docs/admin-guide/demo-mode/)を参照)。

   ![ステップ3: サンプルデータ投入](/docs/screenshots/setup-step3-demoseed.png)

</Steps>

完了すると、ダッシュボードに移動します。

ヘッダーのショップ切替メニューから「ショップの管理...」を選ぶと、ショップ設定画面に入ります(管理者のみ)。同一プラットフォームを複数ショップ、異なるプラットフォームの組み合わせのどちらにも対応しています。ショップの切り替え自体については[ヘッダーとナビゲーション](/docs/user-guide/header/)を参照してください。

![ショップ設定画面](/docs/screenshots/shops.jpg)

## ショップの追加

<Steps>

1. ヘッダーのショップ切替メニューを開く
2. 「+ ショップを追加」からプラットフォームとショップ名を入力して作成する

</Steps>

プラットフォームは「BASE」と「手動管理(API連携なし)」から選べます。BASEのような外部連携APIを持たないサイト向けのショップを作りたい場合は「手動管理」を選ぶと、OAuth連携無しでそのまま商品管理(手動)・[注文の手動登録](/docs/user-guide/orders/#手動管理ショップでの注文登録)が使えるようになります。

ショップ名はカードのヘッダー欄で直接書き換えられ、フォーカスを外すと自動的に保存されます。

## 有効/無効・削除

- **有効/無効**: ショップ名欄横のトグルで切り替えます。  
  無効化するとヘッダーの切替メニューから消えます。  
  「唯一有効なショップ」は無効化できません(トグルがグレーアウトします)。
- **削除**: 「⋮」メニューから行います。  
  紐づく注文・BOM・発注・リストック予約・手動登録商品・在庫変動履歴などを完全に削除します(部品・中間品マスタは他ショップと共有のため残ります)。  
  取り消せない操作のため、確認文字列「ショップを削除」の入力が必須です。

## 手動管理への切り替え

既存のBASEショップは、カード右端の「⋮」メニューの「手動管理に切り替える」から手動管理ショップへ変換できます。  
連携情報(認証)は削除され、以降は商品管理(手動)画面での商品登録と、注文一覧からの手動登録・CSVインポートで運用します。  
既存のBOM・注文データはそのまま残りますが、商品マスタ(商品名・価格・在庫)は新たに登録し直す必要があります。

<Aside type="caution" title="この操作は元に戻せません">
	手動管理から BASE への切り替え(逆方向)はサポートされていません。手動管理ショップの商品マスタはBASE側の商品と対応していないため、安全に戻せないためです。
</Aside>

## 連携設定(URLテンプレート)

プラットフォームを問わず、ショップごとに注文の管理画面URL・商品ページURL・商品編集ページURLのテンプレートを`{unique_key}`・`{item_id}`のプレースホルダー付きで設定できます(手動管理ショップでも、BOOTHなど他サイトの管理画面・商品ページへのリンクとして使えます)。これらは注文一覧・BOM一覧の各行から、実際のショップ管理画面/商品ページへ直接飛ぶ外部リンクに使われます。

<Aside type="note" title="空欄の場合はリンクを表示しません">
	いずれのURLも未設定(空欄)のままなら、対応するリンク自体を表示しません。BASEの標準URLへの自動フォールバックは行わないため、外部リンクを出したい場合は明示的に入力してください。
</Aside>

<Aside type="note" title="同一プラットフォームの他ショップがある場合">
	管理画面(例: `admin.thebase.com`)はプラットフォームのアカウント単位でブラウザにログインする種類のページです。同一プラットフォームのショップが複数あると「今ログインしているのがどのショップのアカウントか」を区別できないため、URLを設定していても管理画面へのリンクは表示されません。商品の公開ページ(ショップごとに固有ドメインを持つ)は影響を受けません。
</Aside>

## BASEとの連携(OAuth)

BASEショップは、この画面のカードで連携状況(緑丸「連携済み」/赤丸「未連携」)を確認し、連携・再認証・連携解除ができます。[デモモード](/docs/admin-guide/demo-mode/)では「BASEとの連携はできません(BASE接続なしで動作しています)」と表示され、連携操作自体ができません。

<FlowDiagram
	steps={[
		{ label: "連携する", sub: "BASEの認可ページが開く", tone: "shop" },
		{ label: "コードを貼り付け", sub: "認可後のURL/コード", tone: "shop" },
		{ label: "連携済み", sub: "以降は自動更新", tone: "shop" },
	]}
/>

<Steps>

1. 「連携する」(連携済みの場合は「再認証する」)を押すと、BASEの認可ページが新しいタブで開く
2. BASEにログインして許可すると、リダイレクト先のURL(またはエラー画面のアドレスバー)に`code=`から始まる認証コードが含まれるので、そのURLごと(またはコード部分だけ)コピーする
3. 画面に表示された「認証コード」欄に貼り付けて「認証する」を押す

</Steps>

連携済みのショップには「自動更新されなかった場合の認証期限」が表示されます(通常は自動更新されるため、期限が近づいても特に操作は不要です)。連携をやめたい場合は「連携解除」を押します。手動管理ショップはそもそも外部連携を行わない設計のため、この画面には連携操作の代わりに商品管理(手動)・注文画面への案内が表示されます。

## 原価を再計算する

[売上](/docs/user-guide/sales/)ページの原価は、注文が発送確定した瞬間の部品・中間品の単価で確定され、以後単価を変更しても自動では変わりません。初めて単価を設定した場合や、単価を見直した後に既存の発送済み注文にも反映したい場合は、ショップごとにカード内の「原価を再計算する」から実行します。

<Aside type="danger" title="この操作は取り消せません">
	対象ショップの発送確定済み全注文の原価を、現在の単価で上書きします。過去の売上ページに表示される粗利の実績値そのものが変わるため、実行前に表示される確認文字列の入力が必須です。デモモードでは実行できません。
</Aside>

サイドバーの「履歴」グループにある2つの画面です。どちらも横断的な確認用の画面で、他の画面(部品編集・注文一覧など)からもリンクで遷移してくることがあります。

## 在庫変動履歴

「部品・中間品の在庫が変わったすべての操作を横断して確認します」という画面です。手動修正・在庫追加・発注入荷・入荷取消し・注文消費・組立・組立材料消費など、在庫数が変わった操作をすべて記録します。

![在庫変動履歴画面](/docs/screenshots/stock-movements-list.jpg)

| 列 | 説明 |
|---|---|
| 日時 | 記録された日時 |
| 対象種別 | 部品 / 中間品 |
| 対象 | 部品・中間品の名前 |
| 変動理由 | 手動修正・在庫追加・発注入荷・入荷取消し・注文消費・組立・組立材料消費など |
| 数量 | 増減した数量(マイナスは消費) |
| メモ | 操作時に入力したメモ(在庫の手動修正時など) |
| 関連 | 関連する注文・発注へのリンク(ある場合) |

対象種別・対象名(部分一致)・変動理由・関連注文ID(部分一致)・期間・ショップで絞り込めます。「共通データを含む」をオンにすると、特定のショップに紐づかない操作(部品在庫は全ショップ共有のため)も含めて表示します。

<Aside type="tip">
	[部品](/docs/user-guide/parts/)・中間品の編集画面にも、その部品/中間品だけに絞った同じ履歴がカードとして表示されます。
</Aside>

## イベントログ

「引当スキップ・在庫操作失敗・自動データ削除など、確認・対応が必要な業務イベントの記録」です。BOM未設定でスキップされた引当や、在庫がマイナスになる操作の失敗など、そのままにしておくと注文処理に支障が出る可能性がある事象がここに記録されます。

![イベントログ画面](/docs/screenshots/event-logs-list.jpg)

| 列 | 説明 |
|---|---|
| 日時 | 記録された日時 |
| レベル | 警告・エラー等の重大度 |
| 種別 | 引当スキップ等のイベント種別 |
| 内容 | 何が起きたか、対応方法の案内を含む具体的な説明文 |
| 関連注文 | 関係する注文ID(あれば) |
| 対象商品 | 関係する商品ID(あれば) |

ショップ・「共通データを含む」で絞り込めます。[注文一覧](/docs/user-guide/orders/)・[BOM編集画面](/docs/user-guide/bom/)から該当するログへのリンクが表示されるので、そこから原因(BOM未設定の商品名など)を直接確認できます。

BOMは「この商品を1個発送するには、部品・中間品を何個消費するか」を商品(商品ID)ごとに登録するものです。サイドバーの「BOM(商品レシピ)」から一覧・編集を行います。

## 一覧

![BOM一覧画面](/docs/screenshots/bom-list.jpg)

画面上部の検索欄で商品名・商品ID・部品名から絞り込めます。商品ごとに、登録済みの部品/中間品と「作成可能数」(すべての消費部品の在庫が続く限り、あと何個作れるか)が表示されます。作成可能数が0の行(赤字)は、いずれかの消費部品の在庫が足りていないことを意味します。

<Aside type="note" title="作成可能数は行ごとに別々に計算される">
	作成可能数は商品につき1つではなく、「共通」行・オプションの選択肢ごと・組み合わせのマスごとに、それぞれ個別に計算されます。同じ商品でも、選ぶオプションによって実質的に作れる数が変わるためです。
</Aside>

商品名の右のアイコンから、その商品の公開ページ・管理画面の編集ページを新しいタブで開けます(ショップ設定でURLを設定している場合のみ。同一プラットフォームの他ショップがあり判別できない場合は編集ページへのリンクは表示されません)。紫色で表示される部品/中間品名は中間品(組み立てて作る半製品)であることを示します。

## 複製して新規作成

行右端の「⋮」の「複製して新規作成」から、既存商品のBOM構成を別の商品にコピーして新規登録できます。すでにBOMが登録済みの商品と、複製元自身は複製先の選択肢から除外されます。

![BOM複製時のコピー確認ダイアログ(オプション名の対応付け)](/docs/screenshots/bom-duplicate-dialog.jpg)

<Steps>

1. 複製先の商品を選ぶと、コピー内容の確認ダイアログが開く
2. 「共通」行(選択肢に関わらず常に消費する部品/中間品)はそのままコピーされる
3. オプション・種類の選択肢は、複製先商品の選択肢名と完全に一致するものだけ自動で対応付けられる。一致しない場合は、下のプルダウンでコピー元のどの選択肢に対応するかを選ぶ(選択肢名が一致していても、いつでも選び直せる)
4. 「◯件をコピー」でBOM編集画面に反映される(この時点ではまだサーバーには保存されない。ここから通常の編集と同様に自由に削除・修正した上で「保存」を押す)

</Steps>

<Aside type="tip" title="選択肢名が一致しなくても複製できる">
	例えば新商品のS/M/Lすべてが、旧商品の「標準」1種類と同じ部品構成である場合、S・M・Lの3つの選択肢すべてから同じコピー元(標準)を選んで対応付けられます。
</Aside>

この機能を試すためのデモ商品として、テスト商品009(複製元)から、テスト商品010(バリエーション名不一致)・テスト商品011(オプション名不一致)への複製を用意しています(いずれもBOM未登録のため、複製先として選べます)。手動管理ショップにも同様にデモ商品001(複製元)→デモ商品004(複製練習用)を用意しています。

## 構成要素

BOMは4種類の行を組み合わせて登録します。

<CardGrid>
	<Card title="共通">オプション・種類の選択に関わらず、常に消費する部品・中間品</Card>
	<Card title="オプション">BASEの商品オプション(例: 「右モジュール」グループの「トラックボール」「キースイッチ」等の選択肢)ごとに、選んだ選択肢の分だけ追加で消費するもの</Card>
	<Card title="種類">単一属性バリエーション(色・サイズ等)ごとに追加で消費するもの</Card>
	<Card title="組み合わせ">複数のオプション/種類の条件を同時に満たす場合だけ追加で消費するもの(例: 「種類=ブラック」かつ「右モジュール=トラックボール」の組み合わせ専用の部品)</Card>
</CardGrid>

商品にオプション・種類の選択肢が複数ある場合、編集画面はオプショングループ・種類ごとにカードが分かれて表示されます。

<Aside type="caution" title="不明なオプション">
	BASE側でオプション構成が変わり、現在の選択肢に該当しなくなった行は「不明なオプション」として別枠に表示されます。商品ページのオプションを変更した後は一度BOM編集画面を確認し、不要な行があれば削除してください。
</Aside>

## 編集画面

![BOM編集画面](/docs/screenshots/bom-edit.jpg)

<Steps>

1. 商品を選ぶ(「変更」から別の商品に切り替えられる)
2. 「共通」テーブルで、常に消費する部品・中間品と数量を登録する
3. オプション・種類・組み合わせがある商品は、それぞれのカードで選択肢ごとの行を登録する
4. 「保存」を押す

</Steps>

<Aside type="caution">
	行を編集しただけでは**サーバーには反映されません**。「保存」を押すまでは全てブラウザ内だけの変更です。一覧画面に戻る前に保存を忘れないよう注意してください。
</Aside>

行を追加する際の「種別」は「部品」「中間品」「部品不要」の3択です。「部品不要」は、その選択肢を選んでも意図的に何も消費しない(自社製造品や無料オプション等)ことを明示するための設定で、行自体が無いのとは区別されます。各行の部品/中間品名の横の小さい数字は現在の利用可能数で、0以下だと赤く表示されます。

「共通」テーブルには「原価」列と、その合計を示す「見積原価」の行が表示されます(部品/中間品に単価・追加費用を設定した場合のみ計算されます)。オプション・種類・組み合わせのカードは、同時に選べない選択肢が並ぶため合計は表示されず、行ごとの原価だけが表示されます(組み合わせのマス内は同時に消費される行なので、マスごとの見積原価が表示されます)。

## 組み合わせの編集

「組み合わせ」カードでは、2つの軸(オプショングループ/種類)を選ぶとその掛け合わせのマス目が表になって表示され、必要なマスだけ部品/中間品と数量を入力してまとめて登録できます。1つずつ行を追加するより効率的です。

![組み合わせの編集(軸の選択とグリッド入力)](/docs/screenshots/bom-combo-grid.png)

<Steps>

1. 「軸1(縦)」「軸2(横)」でそれぞれ別の軸(オプショングループまたは種類)を選ぶ
2. 表が現れるので、必要なマスだけ部品/中間品名(入力すると候補が出る)と数量を入力する(空欄のマスは無視される)
3. 「表の内容を組み合わせとして追加」を押す

</Steps>

<Aside type="note">
	軸が3つ以上ある商品では、2軸を選んだ後に残りの軸を「(軸名)を固定(任意)」で1つに絞り込んでから表を作ることもできます。また、組み合わせのマスには「部品不要」の指定はできません(部品/中間品名を空欄のままにすると、そのマスは追加されません)。
</Aside>

登録済みのマスにカーソルを合わせると「↓」「→」のコピーボタンが表示され、そのマスの内容を同じ列の残り全セル(↓)、または同じ行の残り全セル(→)にまとめてコピーできます。コピー先の既存内容は上書きされます。色違いのケースなど、複数の選択肢で同じ部品構成を繰り返し登録したい場合に使います。

## 中間品への変換・展開

BOM編集画面の「共通」カード右上の「⋮」から「行を選んで中間品にする」を選ぶと、選択モードに切り替わります。同じ条件(共通/同じオプション選択肢など)の行を複数チェックして「中間品にする」を押すと、選んだ行をまとめて新しい中間品として登録し、BOM側はその中間品1行に置き換えられます。何度も一緒に使われる部品の組み合わせを、まとめて管理したい場合に使います。

逆に、中間品としてまとめた構成を特定の1箇所だけ元の部品構成に戻したい場合は、[中間品の編集画面の「使用箇所」](/docs/user-guide/parts/#使用箇所)から展開します。

## CSVインポート/エクスポート

一覧画面右上の「エクスポート」で、全商品のBOMをCSV(列: `item_id, item_name, component_type, component_sku, component_name, quantity, conditions`)としてダウンロードできます。「インポート」で同じ形式のCSVを取り込むと、既存の行はSKUで突き合わせて更新し、新しい行は追加されます。取り込み後は「インポート結果: 新規○件・更新○件」が表示され、行ごとのエラー(`component_type`が不正、数量が正の整数でない等)があれば一覧されます(エラー行番号はCSVのヘッダー行を1行目として数えます)。

## 注文一覧のPDF出力とマトリクス表示

BOM編集画面の「注文一覧PDF出力時、オプションを横並びの表にする」にチェックを入れると、その商品はピッキング・注文一覧のPDF出力時にExcel風のマトリクス表(オプションの組み合わせを行×列で表示)として出力されます。チェックしない商品は、他の商品と同じカード形式で出力されます。同一PDF内に両方の形式を混在させられます(詳しくは[注文・ピッキング](/docs/user-guide/orders/)を参照)。

## 作成可能数アラート

BOM編集画面の「作成可能数アラートの閾値」に数値を設定すると、その商品の作成可能数(共通行・オプションの選択肢ごと・組み合わせのマスごとに算出したうち最小の値)が閾値を下回った時、[設定画面の通知](/docs/admin-guide/settings/#通知)(Webhook/メール)が送信されます。未設定の商品はアラート対象外です。

サイドバーの「リストック予約」から、指定した日時にショップ側の在庫数を自動更新する予約を作成できます。物理的な部品在庫のスケジュールではなく、**ショップに公開する在庫数**(何個までカートに入れられるか)を予約設定する機能です。再入荷のタイミングに合わせて自動で在庫を復活させたい場合などに使います。

![リストック予約一覧画面](/docs/screenshots/schedules.jpg)

## 使い方

<Steps>

1. 「新規作成」から、商品を選ぶ(コンボボックスで検索するか、候補に無ければ「IDとして直接指定」で商品IDを直接入力できる。存在しないIDの場合は「商品が見つかりません」と表示される)
2. 更新後の在庫数と、実行日時(初期値は1分後)を指定して作成する
3. バックエンドが30秒間隔でポーリングし、実行日時が到来した予約を自動実行する
4. 一覧画面で実行結果を確認する

</Steps>

| 状態 | 説明 |
|---|---|
| <Badge text="待機中" variant="note" /> | まだ実行日時が来ていない。一覧の行をクリックすると編集画面が開く(在庫数・実行日時のみ変更可能、商品は変更できない) |
| <Badge text="実行中" variant="note" /> | ちょうど実行処理が行われている |
| <Badge text="成功" variant="success" /> | 在庫数の更新に成功した |
| <Badge text="失敗" variant="danger" /> | 更新に失敗した(結果列にエラー内容が表示される) |

<FlowDiagram

実行前(待機中)の予約は一覧から「キャンセル」できます。同一商品IDに対して重複した待機中の予約は作成できません(API側で409エラーになる)。

<Aside type="caution" title="制約">
	バリエーション商品(サイズ・カラー違い等、複数の在庫数を持つ商品)の在庫更新は現バージョンでは非対応です。
</Aside>

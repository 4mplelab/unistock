ログイン後、最初に表示される画面です。在庫・注文・部品の状況をひと目で把握できます。

![ダッシュボード画面](/docs/screenshots/dashboard.jpg)

## 各カードの見方

<CardGrid>
	<Card title="発注が必要な部品">発注点(利用可能数の下限)を下回った部品の一覧。行をクリックすると編集画面へ。「発注する」から数量・納品予定日・発注URLを入力してその場で発注記録を作成できる(すでに発注中の場合は「発注中」バッジが代わりに表示される)</Card>
	<Card title="発注中">まだ入荷していない発注。納期(納品予定日)を過ぎているものは赤字で表示される。行をクリックすると[発注管理](/docs/user-guide/purchase-orders/)へ</Card>
	<Card title="売上サマリ">選択中のショップの、直近30日の発送確定分の総売上・粗利率・注文件数・平均注文単価。「詳しく見る」から[売上](/docs/user-guide/sales/)ページへ</Card>
	<Card title="マイナス在庫の警告">利用可能数が0未満になっている部品・中間品(通常は起こらないが、発生した場合は原因調査が必要)。行をクリックすると編集画面へ</Card>
	<Card title="ピッキング状況">未対応の注文数と、そのピッキング進捗(完了率のリング表示)。「ピッキングを開く」からそのまま[ピッキング画面](/docs/user-guide/orders/#ピッキング)へ</Card>
	<Card title="直近のイベントログ">引当スキップ・在庫操作失敗など、確認が必要な業務イベントの最新分。行をクリックすると[イベントログ](/docs/user-guide/history/)の該当箇所へ</Card>
	<Card title="リストック予約">まだ実行されていない在庫プッシュ予約を、実行日時が近い順に表示(選択中のショップのみ)。[リストック予約](/docs/user-guide/schedules/)が存在しない手動管理ショップを見ているときは表示されない</Card>
	<Card title="部品消費トレンド">直近30日で消費数量が多い部品・中間品の上位5件</Card>
	<Card title="発注リードタイム分布">過去の発注が、発注から入荷までどのくらいかかったかの分布(0-1日/2-3日/4-7日/8-14日/15-30日/31日以上の6段階)。次に発注するタイミングの目安になる</Card>
	<Card title="中間品組立稼働状況">中間品の組立実績</Card>
</CardGrid>

サイドバーの各メニュー項目に付いている件数バッジも、ダッシュボードの一部のカードと対応しています(例: 「発注中」の件数と、サイドバー「発注管理」のバッジは同じ数)。ただし「発注が必要な部品」はダッシュボード専用の表示で、対応するサイドバーのバッジはありません。

## 発注が必要な部品

ダッシュボードの「発注が必要な部品」に、発注点(利用可能数の下限)を下回った部品が自動で表示されます。「発注する」ボタンから、そのままその部品の発注記録を作成できます。ダッシュボードには過去の発注の「発注リードタイム分布」(発注から入荷までにかかった日数の傾向)も表示され、次にどのくらい早めに発注すべきかの目安になります。

<Aside type="note">
	[部品](/docs/user-guide/parts/)側で「発注管理する」をオフにしている部品は、在庫が減っても「発注が必要な部品」には出てきません。
</Aside>

## 発注一覧

![発注管理画面](/docs/screenshots/purchase-orders.jpg)

サイドバーの「発注管理」で、発注記録の一覧・入荷処理を行います。発注記録は発注時点のショップに紐づきますが、部品在庫自体は全ショップで共有しているため、一覧はどのショップを選択していても常に全ショップ分をまとめて表示します(どのショップの発注かは一覧の「ショップ」列で分かります)。画面上部の「状態」ドロップダウンと「部品名」検索欄で絞り込めます。

| 状態 | 説明 |
|---|---|
| <Badge text="発注中" variant="caution" /> | まだ入荷していない発注。ダッシュボードの「発注中」カードにも表示され、経過日数が列に表示される。納期(任意入力の納品予定日)を過ぎているものは赤字で「(納期超過)」と表示される |
| <Badge text="入荷済み" variant="success" /> | 「入荷」ボタンから入荷日時を記録すると、部品の在庫数が発注数量ぶん増える |
| <Badge text="キャンセル" variant="danger" /> | 入荷せずに発注を取り消した記録 |

## 一覧からの操作

<CardGrid>
	<Card title="入荷">
		![入荷ダイアログ](/docs/screenshots/purchase-order-receive-dialog.png)

		入荷日時(初期値は現在時刻)を入力して記録します。部品の在庫数が発注数量ぶん増えます
	</Card>
	<Card title="発注URLの編集">
		![発注URLダイアログ](/docs/screenshots/purchase-order-url-dialog.png)

		実際に仕入れ先サイト等で発注した後のページURLを、発注記録作成後に任意で追記・編集できます。一覧の鉛筆アイコンから開き、外部リンクアイコンから開けます
	</Card>
</CardGrid>

このほか「その他の操作」メニュー(⋮)から、入荷済みの発注を取り消す**入荷取消し**(加算した在庫数を戻す)、発注中の記録を入荷せずに取り消す**キャンセル**ができます。

サイドバーの「売上」では、発送確定(対応済)になった注文をもとに売上・原価・粗利益を集計して確認できます。

![売上ページ上部(サマリーカードとグラフ)](/docs/screenshots/sales-summary.jpg)

<Aside type="note" title="集計の考え方">
	総売上・注文件数・平均注文単価は、注文詳細から取得した注文合計金額(送料・代引き手数料・割引を含み、キャンセル済み商品は最初から除外済みの金額。[注文一覧](/docs/user-guide/orders/)の「金額」列と同じ値)を使います。商品別ランキングは、この合計金額を商品ごとに配分できないため、商品明細ごとの金額(単価だけでなくオプションの追加料金も含む)の合計を使っており、送料等は含まれない分だけ総売上の内訳と厳密には一致しません。いずれの金額も取得できていない古い注文は、代わりに「単価 × 数量」の合計で計算します。集計対象は常に発送確定(対応済)になった注文のみで、「日付の基準」の設定に関わらず変わりません(未発送・キャンセルの可能性がある注文の金額は、後で数字が変わってしまうため一切含めません)。
</Aside>

画面右上の「ショップ」「期間」「日付の基準」で絞り込めます。ショップは「全て」(全ショップ横断の合計)と個別ショップを切り替えられ、ヘッダーの現在選択ショップとは独立した、このページだけの設定です。期間は直近7日・30日・90日から選べます。

「日付の基準」は、グラフを何の日付で集計するかの切り替えです。

- **発送日基準**(既定): 発送が確定した日で集計する、実績としていつ確定したかを見る基準
- **注文日基準**: 注文があった日で集計する、需要がいつ発生したかを見る基準(セール等の効果測定に向く)

<Aside type="caution" title="注文日基準は直近の日が後から積み上がります">
	注文日基準でも対象は発送確定済みの注文のみです。そのため、まだ発送し終わっていない注文がある直近の日は実際より少なく表示され、発送が進むにつれて後から数字が積み上がっていきます(発送日基準ではこの遡りは起きません)。
</Aside>

## サマリーカード

- **総売上・注文件数・平均注文単価**: 選択した期間の合計値
- **総原価・総粗利・粗利率**: 実際に引き当てた部品/中間品の原価をもとに算出

<Aside type="note" title="原価の計算方法">
	原価は、部品・中間品の登録画面で「単価(円)」を設定した場合のみ計算されます(未設定の部品/中間品は0円扱い)。中間品の原価は現在の設定値(組成する部品の原価合計 + 中間品自身の「追加費用」)で計算するため、原価を変更する前の古い注文でも、常に現在の原価水準で計算した参考値になります。実際に消費した部品/中間品の内訳(注文取り込み時点の引当記録)を使うため、BOMを後から変更しても過去の注文の原価は変わりません。
</Aside>

## グラフ

- **売上高の内訳(原価・粗利)**: 選んだ日付の基準ごとの売上高を、原価と粗利の積み上げ棒グラフで表示(棒の高さ=売上)
- **注文件数推移**: 選んだ日付の基準ごとの注文件数
- **粗利率推移**: 選んだ日付の基準ごとの粗利率。売上が無い日は線が途切れます(0%と表示すると「その日は赤字だった」ように誤解されるため)

## 商品別グラフ

商品別の売上または件数を横棒グラフ・円グラフのどちらかで表示します。カード右上で以下を切り替えられます。

- **カテゴリ**: 「すべてのカテゴリ」(全体の上位10件)、または特定のカテゴリを選ぶとそのカテゴリ内の商品だけに絞り込む
- **売上 / 件数**: 集計する指標
- **棒グラフ / 円グラフ**: 表示形式(円グラフは選んだ指標の構成比を表示)

## カテゴリ別構成比

![カテゴリ別売上構成比と商品別ランキング](/docs/screenshots/sales-ranking.jpg)

商品カテゴリ(部品/中間品のグループとは別に、連携先のショップ側で商品に設定するカテゴリ)ごとの売上・件数の構成比を円グラフとランキングリストで表示します。カード右上の「売上 / 件数」で指標を切り替えられます。

<Aside type="note">
	商品カテゴリは、現時点ではBASEショップの商品のみ同期対応しています(手動管理ショップの商品は常に「未分類」扱いです)。
</Aside>

<Aside type="caution" title="構成比が100%を超えることがあります">
	1つの商品が複数のカテゴリに属している場合、該当する各カテゴリにその商品の実績をそのまま計上するため、構成比の合計が100%を超えることがあります。カテゴリが未設定の商品は「未分類」としてまとめます。カテゴリ情報は数時間おきに連携先から自動で同期されるため、連携先でカテゴリを変更した直後は反映まで少し時間がかかることがあります。
</Aside>

## 商品別ランキング

売上が多い商品の上位10件を、数量・売上・原価・粗利・粗利率の列で表示します。

<Aside type="danger" title="注文データを消すと、その分の売上も消える">
	このページは注文データをその場で集計しているだけで、売上専用の記録は別に保存していません。[設定画面](/docs/admin-guide/settings/#データ管理)の「注文履歴のみ消去」「全データを消去」や、保持日数を設定した「自動データ削除」で対象期間の注文が削除されると、その期間の売上も二度と表示できなくなります(自動データ削除は既定で無効=無期限保持のため、設定しない限り自動では消えません)。
</Aside>

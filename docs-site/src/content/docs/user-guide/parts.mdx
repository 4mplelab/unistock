サイドバーの「部品」「中間品」から、それぞれの一覧・登録・編集を行います。部品は最小単位の在庫、中間品は部品(または他の中間品)を組み立てて作る半製品です。

## 部品一覧

![部品一覧画面](/docs/screenshots/parts-list.jpg)

| 列 | 説明 |
|---|---|
| 名前 / タグ | 部品名と、検索・絞り込みに使えるタグ |
| SKU | 管理用の識別コード |
| グループ | 「M3ナット」「M3ネジ」のように、部品をまとめる分類名(任意) |
| 利用可能 | 実際の在庫数から引当中の数量を差し引いた、今すぐ使える数量。マイナスになった場合は赤字で表示されます |
| 発注点 | 利用可能数がこの数値を下回ると「発注が必要な部品」に表示される基準値。未設定の部品は「-」 |
| 単価 | 原価計算用の金額(円)。未設定の部品は「-」(売上ページの原価集計では0円扱い) |

<Aside type="note" title="「利用可能」の内訳バッジ">
	「利用可能」の右に付く小さいバッジは、その数量の内訳です。**引当**(進行中の注文に確保済みで発送を待っている数量)と**発注中**(発注済みでまだ入荷していない数量)の2種類があり、どちらも0のときは表示されません。
</Aside>

発注点を下回った部品はダッシュボードの「発注が必要な部品」に自動で表示されます。「引当」バッジをクリックすると、その部品を引き当てている注文の一覧(「引当中の注文」ダイアログ)が開きます(対象注文が1件だけの場合はダイアログを挟まずピッキング画面へ直接遷移します)。

名前欄の左にある検索欄(名前・SKU・タグで検索)と「グループ」ドロップダウンで一覧を絞り込めます。「グループでまとめる」を有効にすると、絞り込みで1グループに絞らなくても、一覧全体がグループ→名前の順に並び替わり、グループごとに見出し行が挟まれます。色違いなど同じグループの部品をまとめて見比べたいときに使います(グループ未設定の部品は末尾にまとまります)。

## 一覧からの操作

各行のアイコンから、編集画面を開かずにその場でできる操作です。

<CardGrid>
	<Card title="在庫を追加する">
		![在庫を追加するダイアログ](/docs/screenshots/part-stock-add-dialog.png)

		「追加数量」と任意のメモを入力してその場で在庫数を加算します(発注は行われません)。メモは[在庫変動履歴](/docs/user-guide/history/)に記録されます
	</Card>
	<Card title="発注する">
		![発注するダイアログ](/docs/screenshots/part-order-dialog.png)

		「発注管理する」がオンの部品にのみ表示。数量(発注点との差分が初期値)・納品予定日(任意)・発注URL(任意、後から追記も可)を入力して発注記録を作成します。作成後は[発注管理](/docs/user-guide/purchase-orders/)で管理します
	</Card>
</CardGrid>

「その他の操作」メニューには「複製して新規作成」もあります。名前・タグ・グループ・色・単価・購入先URL・発注点などを引き継いだ状態で新規作成画面が開きます(在庫数は0、SKUは空欄からになります)。中間品の場合は組成(レシピ)も一緒に複製されます。似た部品・中間品を登録するときのショートカットとして使えます。

削除は同じメニューから確認ダイアログを挟んで行います。BOMで使用中の部品は削除できません。

## 登録・編集する項目

<CardGrid>
	<Card title="基本情報">名前・SKU・タグ・単価(円、任意)・購入先URL</Card>
	<Card title="在庫">在庫数・発注点・グループ・色。在庫数を直接変更する場合は、その理由をメモに残せます(在庫変動履歴に記録される)</Card>
	<Card title="発注管理">「発注管理する」をオフにすると発注点の設定自体が無くなり、仕入れ先への発注は行わず在庫追加のみで管理する部品(自社製造品など)として扱える</Card>
	<Card title="メモ">自由記述の備考欄</Card>
</CardGrid>

タグは検索・絞り込みに使えます(カンマ区切りで複数入力可、上限あり)。色は部品を色違いで複数登録する場合(例: ケースのブラック/ホワイト)に使い、一覧上で色見本(丸いスウォッチ)として表示されます。色の選択肢自体は管理者が[設定画面の「部品のカラーパレット」](/docs/admin-guide/settings/#部品のカラーパレット)で管理します。

編集画面には「在庫変動履歴」カードも表示され、その部品の在庫が変わった操作(手動修正・在庫追加・発注入荷・注文消費など)を確認できます(詳しくは[在庫変動履歴とイベントログ](/docs/user-guide/history/)を参照)。

CSVのエクスポート・インポートに対応しています(一覧画面右上のボタンから。部品・中間品どちらの一覧にもあります)。既存の行はSKUで突き合わせて更新し、新しいSKUの行は新規作成されます。取り込み後は「インポート結果: 新規○件・更新○件」と、行ごとのエラーがあれば一覧表示されます。

商品(BOM)を選ぶコンボボックスなど、アプリ全体で部品・中間品を選ぶ場面では、名前・SKU・色をまとめて検索できる共通の選択UIを使っています。

## 中間品と組立

![中間品一覧画面](/docs/screenshots/assemblies.jpg)

中間品は部品・中間品どちらも材料にでき、多段構成(中間品の材料がさらに中間品、という入れ子)にも対応します。ただし循環参照(AがBを材料にし、BがAを材料にする、等)は登録時に弾かれ、材料の選択肢にも編集中の中間品自身は現れません。削除ボタン(BOMで使用中は削除不可)は部品と同様です。

一覧の「原価」列は、組成する部品・中間品の原価合計に、この中間品自身の「追加費用」(下記)を足した金額です。カーソルを合わせると内訳(部品原価合計 + 追加費用)が確認できます。

### レシピ(組成)の編集

中間品の詳細画面の「組成(レシピ)」カードで、材料にする部品・中間品を登録します。「種別」(部品/中間品)を選び、材料をコンボボックスで選び、数量を入力して「行を追加」します。登録済みの各行には利用可能数の小さいバッジが付き、0以下だと赤く表示されます。同じ画面には、その中間品だけに絞った在庫変動履歴も並んで表示されます。

![組成(レシピ)編集と在庫変動履歴](/docs/screenshots/assembly-recipe-and-history.png)

<Aside type="note" title="追加費用">
	編集画面の「追加費用(円)」は、組み立て工賃・外注費など、部品原価だけでは表せない追加費用です。中間品自体の原価は「追加費用 + レシピの部品原価合計」として自動計算されるため、そういった費用が無ければ0円のままで構いません。
</Aside>

### 使用箇所

編集画面の「使用箇所」カードには、その中間品が実際に使われているBOMの行・他の中間品のレシピが一覧表示されます。行の「展開する」を押すと、その箇所をこの中間品のレシピ内容で個別の行に置き換えられます(確認ダイアログを挟みます)。中間品としてまとめていた構成を、特定の1箇所だけ元の部品構成に戻したい場合に使います。

### 組み立てる

<Steps>

1. 一覧またはレシピ編集画面から「組み立てる」を実行する
2. ダイアログで数量と任意のメモを入力する
3. レシピに従って材料を消費し、中間品自体の在庫が増える(組立履歴として記録される)

</Steps>

![組み立てるダイアログ](/docs/screenshots/assembly-build-dialog.png)

材料が不足している場合はエラーになり、組立は実行されません。レシピが未設定の中間品(一覧に「レシピ未設定」と表示される)は、BOMで使われていても部品を消費できないため、注文の引当がスキップされます。

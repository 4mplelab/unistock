サイドバーの「商品管理(手動)」は、[手動管理ショップ](/docs/admin-guide/shops/#手動管理への切り替え)(BASEのような外部連携APIを持たないサイト向け)を選択しているときだけ表示されます。BASEショップでは商品情報(商品名・在庫・価格)を都度BASEから取得しますが、手動管理ショップには問い合わせ先が無いため、この画面で登録した内容が在庫・価格の一次情報になります。

<Aside type="note">
	BASEショップを選択している間はこのメニュー項目自体が表示されません。逆に手動管理ショップを選択している間は、BASE向けの「リストック予約」メニューが非表示になります。
</Aside>

## 商品一覧

![商品管理(手動)の一覧画面](/docs/screenshots/manual-items-list.jpg)

商品コード・商品名・価格・在庫・登録済みバリエーション件数が並びます。バリエーションを持つ商品は、価格列に各バリエーションの名前と価格が一覧表示されます(バリエーションを持つ商品自体は共通価格を持たないため)。行をクリックすると編集画面が開きます。右端には2つの操作があります。

- **在庫を消費するアイコン**: [BOM](/docs/user-guide/bom/)で紐付けた部品・中間品の在庫を、注文を作らずにまとめて減らします。イベント頒布・店頭販売など、注文という形で記録したくない消費に使います。数量を指定して実行すると、その商品自身の在庫と、BOMで紐付いた部品・中間品の在庫が同時に減算されます。部品の在庫が足りない場合は何も変更されずエラーになります。**バリエーションを持つ商品は、必ずどのバリエーションを消費するか選ぶ必要があります**(商品本体の在庫が、バリエーションを介さず単独で減ることはありません)
- **「⋮」**: 「複製して新規作成」「削除」(削除は確認ダイアログを挟みます)

「複製して新規作成」を使うと、商品名・価格・メモ・バリエーションを引き継いだ状態で新規作成画面が開きます(商品コード・在庫数は0/空欄からになります)。似た商品を登録するときのショートカットとして使えます。

## 商品を追加

右上の「新規作成」から専用の登録画面が開き、商品コード・商品名・価格・在庫数を入力します。商品コードは一意な識別コードで、あとから変更できません。価格は任意項目(未入力可)ですが、商品コード・商品名・在庫数は必須です。

同じ画面でバリエーション(下記)も同時に登録できます。「作成」を押すとまとめて登録されます。バリエーションを1件でも追加すると、価格欄はこの画面から消えます(下記参照)。

## 編集画面とバリエーション

![商品管理(手動)の編集画面とバリエーション](/docs/screenshots/manual-items-edit.jpg)

編集画面では商品名・価格・在庫数・メモと、バリエーション(色・サイズなど、商品が持つ単一軸の選択肢)の行の追加・修正・削除をまとめて編集し、右上の「更新」で一度に保存します。バリエーションはBASEの「バリエーション」機能と同じ形で、[BOM編集画面](/docs/user-guide/bom/)の「種類」(単一選択肢)条件としてそのまま使えます。複数のオプショングループを組み合わせる「オプション」機構には対応していません。

バリエーションの「価格」は、本体価格に上乗せする差額ではなく、そのバリエーションを選んだときに使う独立した価格です。バリエーションを1件でも登録すると、商品本体(共通)の価格欄は編集画面から消えます。取引(注文・CSVインポート・在庫消費)は必ずいずれかのバリエーションを経由し、共通の価格が単独で使われることは無いためです。

バリエーションの行自体は、価格を空欄のまま追加できます(例: 「赤」「青」「黄」と名前だけ先に3行並べる)。全バリエーションに共通の価格を1件ずつ手入力する手間を省きたい場合は、バリエーション一覧の上にある「価格を一括設定」に金額を入力して「全バリエーションに適用」を押すと、その時点で登録済みの全バリエーションの価格をまとめて書き換えられます。

<Aside type="caution">
	価格が未設定のバリエーションが1件でも残っていると、この商品自体を保存(作成・更新)できません。また、保存できていたとしても、価格が未設定のバリエーションでは注文・CSVインポートができません(「価格が設定されていません」というエラーになります)。バリエーションを追加したら、価格も忘れずに入力してください。
</Aside>

<Aside type="caution" title="商品コードは変更できません">
	商品コードはBOM・注文明細から参照されるキーのため、作成後の変更はできません。コードを直したい場合は削除して登録し直してください。削除してもBOM・過去の注文明細にはその時点の商品名がそのまま残ります(BASEで商品が削除された場合と同じ扱いです)が、BOM編集画面の商品選択やバリエーション選択には出てこなくなるため、削除前にBOMで使用していないか確認してください。
</Aside>

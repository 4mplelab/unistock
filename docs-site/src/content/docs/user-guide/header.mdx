画面上部のヘッダーと、左側のサイドバーがUniStockの基本的な操作の起点です。

## サイドバー

左側のメニューから各画面に移動します。グループごとに分かれています。番号は下の画像の番号と対応しています。

| # | グループ | 画面 |
|---|---|---|
| 1 | (グループなし、最上部) | ダッシュボード |
| 2 | マスタ | 部品、中間品、BOM(商品レシピ) |
| 3 | 発注 | 発注管理 |
| 4 | ECサイト連携 | リストック予約 |
| 5 | 注文 | 注文、ピッキング |
| 6 | 履歴 | 在庫変動履歴、イベントログ |

件数バッジ(数字の丸)が付いている項目は、対応が必要な件数(未対応の注文・未完了のピッキング等)を表します。件数バッジと、ダッシュボードの各カードの見方は[ダッシュボード](/docs/user-guide/dashboard/)を参照してください。

## ヘッダーのアイコン

右上に並ぶアイコンは、左から次の役割です。番号は下の画像の番号と対応しています。

![ヘッダーのアイコン](/docs/screenshots/header-icons.png)

<Aside type="note">
	通知ベルは管理者にのみ表示されます。一般ユーザーには表示されません(「?」アイコンはログイン中の全ユーザーに表示されます)。
</Aside>

1. **ショップ切替**: 操作対象のショップを選ぶ。複数ショップを運用している場合、注文・BOM・在庫スケジューラーなど、ショップに紐づく画面はここで選んだショップのデータを表示する(部品在庫は共有なので変わらない)
2. **外観切替**: ライト/ダーク/システムに従う、をクリックで順に切り替える
3. **通知ベル**: 新しいバージョンの通知など、システムからのお知らせを表示する(管理者のみ)
4. **「?」アイコン**: このドキュメントサイトを新しいタブで開く(ログインなしでも直接アクセス可能)
5. **アカウントアイコン**: ログイン中のアカウント名・メールアドレスを表示し、ログアウトできる

「デモモード」バッジがある場合は、実際のショップに接続していない試用環境であることを示します。

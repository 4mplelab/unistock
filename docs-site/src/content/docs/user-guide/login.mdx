UniStockを開くと、まずログイン画面が表示されます(デモモードを除く)。

## 通常モード

サーバー管理者が設定したプロバイダ(Google/Microsoft/GitHub/Xのいずれか)のボタンが表示されます。ボタンを押すとそのプロバイダの認証画面に移動し、許可すればUniStockに戻ってログイン完了です。

![通常モードのログイン画面](/docs/screenshots/login-normal.png)

<Aside type="caution" title="「このアカウントにはUniStockへのアクセス権がありません」と出たら">
	ログインできるアカウントは、管理者があらかじめ「許可ユーザー」として登録したものだけです。このエラーが出た場合は、ログインしようとしたメールアドレス(X の場合はアカウント名)を管理者に伝えて、[許可ユーザーとして登録](/docs/admin-guide/settings/#許可ユーザー)してもらってください。登録後、もう一度同じ方法でログインすれば入れます。
</Aside>

## デモモード

実際のログイン処理は行われません。「デモを試す」ボタンを押すだけで、デモ用の管理者アカウントとしてすぐに使えます。

![デモモードのログイン画面](/docs/screenshots/login-demo.png)

## ログアウト

ヘッダー右上のアカウントアイコンから「ログアウト」を選べます(デモモードではログイン処理自体が無いため、ログアウトしても再度「デモを試す」で戻れるだけです)。

## ユースケース: 新しいメンバーを招待する

<Steps>

1. 管理者が、招待したい人のメールアドレスを[設定 → 許可ユーザー](/docs/admin-guide/settings/#許可ユーザー)に登録する
2. 招待された本人が、UniStockのURLを開き、そのメールアドレスで対応するプロバイダ(Google等)からログインする
3. 初回ログインと同時にアカウントが有効になり、以降は同じ方法でいつでもログインできる

</Steps>
